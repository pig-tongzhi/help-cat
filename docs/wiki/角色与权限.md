# 角色与权限

## 角色定义

### USER（志愿者/普通用户）

- 浏览公开猫咪、小区和开放任务。
- 注册、登录、退出和恢复自己的会话。
- 提交猫咪档案；每天最多 3 条，默认进入待审核。
- 上传自己用于猫咪档案的图片。
- 提交小区建议，默认进入待审核。
- 查看自己的猫咪和小区提交。
- 领取开放救助任务。

### ADMIN（管理员）

拥有 USER 能力，并额外拥有：

- 新增小区并立即开放。
- 修改、审核、隐藏和归档小区。
- 创建猫咪档案并直接审核通过。
- 审核、公开、隐藏和归档猫咪档案。
- 创建救助任务。
- 进入管理后台。

管理员不能查看全量用户列表，不能授予或撤销管理员角色。

### SUPER_ADMIN（唯一超级管理员）

拥有 ADMIN 全部能力，并额外拥有：

- 查看用户列表。
- 将普通用户设为 ADMIN。
- 将 ADMIN 撤回 USER。

唯一超级管理员不能通过角色接口被降级或替换。当前生产唯一超级管理员账号为项目所有者账号；Wiki 不记录密码。

|---|:---:|:---:|:---:|
| 浏览公开内容 | ✓ | ✓ | ✓ |
| 提交待审猫咪 | ✓ | — | — |
| 创建直接公开猫咪 | — | ✓ | ✓ |
| 提交待审小区 | ✓ | — | — |
| 新增直接开放小区 | — | ✓ | ✓ |
| 审核/归档小区 | — | ✓ | ✓ |
| 审核/隐藏/归档猫咪 | — | ✓ | ✓ |
| 创建救助任务 | — | ✓ | ✓ |
| 进入管理后台 | — | ✓ | ✓ |
| 查看所有用户 | — | — | ✓ |
| 授予/撤销 ADMIN | — | — | ✓ |
| 修改 SUPER_ADMIN | — | — | — |

## 后端强制规则

- `require_admin()` 只接受 `ADMIN` 或 `SUPER_ADMIN`。
- `require_super_admin()` 只接受 `SUPER_ADMIN`。
- 未登录、Token 过期或被撤销返回 401。
- 用户被停用返回 403。
- 普通用户直接调用管理接口返回 403，即使手工构造请求或修改前端 DOM。
- `RoleUpdate` 只接受 `USER` 或 `ADMIN`，不能通过请求制造第二个 `SUPER_ADMIN`。
- 目标用户已经是 `SUPER_ADMIN` 时，角色修改返回 `super_admin_immutable`。

## 前端展示规则

- 角色值先转成大写并规范化；未知值按 `USER` 最小权限展示。
- USER 不显示“进入管理后台”。
- ADMIN 显示“管理员账号 · 新建档案将直接公开”。
- SUPER_ADMIN 显示“超级管理员账号 · 新建档案将直接公开”。
- 管理后台再次调用 `/api/v1/auth/me`，拒绝普通用户 Token。

## 审计要求

以下操作写入 `audit_logs`：

- 创建、修改、审核和归档小区。
- 创建、审核、公开/隐藏和归档猫咪。
- 上传媒体文件。
- 创建和领取任务。
- 授予或撤销管理员角色。

当前尚未提供审计日志查询 API 和管理界面，列入未实现功能。
