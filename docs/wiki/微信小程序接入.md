# 微信小程序接入

本页区分当前代码骨架和正式上线要求。微信平台规则可能调整，实施时必须再次以微信开放文档和公众平台控制台为准。

## 当前已有代码

目录：`miniapp/`

```text
app.json                         页面与窗口配置
app.js                           API 地址和 Token 恢复
utils/api.js                     wx.request / wx.login / wx.uploadFile
pages/home/                      小区、猫咪浏览和搜索
pages/cats/new/                  猫咪建档、定位、相册/相机、上传
pages/submissions/               我的提交
pages/tasks/                     任务列表和领取
```

已经存在的调用：

- `wx.login` 获取临时登录 code。
- `POST /api/v1/auth/wechat-login` 换取 Help Cat Session。
- `wx.chooseMedia` 同时允许 `album` 和 `camera`。
- `wx.uploadFile` 上传图片。
- `wx.request` 调用公开与登录 API。

## 当前不能正式上线的原因

1. `miniapp/app.js` 的 API 地址仍是 `https://api.example.com`。
2. 后端 `WechatProvider` 只支持测试 `fake:` code；真实 code 会返回 `wechat_provider_pending`。
3. 生产入口是 HTTP + IP，不满足正式网络请求配置。
4. 尚未配置小程序 AppID/AppSecret 和 request/uploadFile/downloadFile 合法域名。
5. 尚未完成用户隐私保护指引、用户协议、账号注销和数据删除流程。
6. 没有小程序端管理员入口、错误状态设计和完整真机回归。
7. 没有发布版本、体验版验证和微信审核材料。

## 正式接入顺序

### 1. 域名与 HTTPS

- 使用审核通过且由项目控制的域名。
- 在生产 Nginx 配置域名站点和有效 TLS 证书。
- 强制 HTTP 跳转 HTTPS。
- 保留 HSTS 前先确认所有子域都能稳定使用 HTTPS。
- 在中国大陆部署时，根据服务商和主管部门要求完成必要备案；实际要求以当时平台页面为准。

微信网络请求要求和域名配置见官方文档：<https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html>。

### 2. API 域名

推荐统一使用一个 HTTPS 域名，例如：

```text
https://help-cat.example.com/help-cat-api/api/v1
```

在微信公众平台配置与实际调用对应的 request、uploadFile 和 downloadFile 合法域名。不要把 IP、HTTP 地址或本地测试地址写入发布版。

### 3. 微信登录 Provider

客户端：

1. 调用 `wx.login` 获取一次性 code。
2. 把 code 发送到 Help Cat 后端。

后端：

1. 从安全环境变量读取 AppID/AppSecret；不能写进仓库或小程序包。
2. 调用微信 code2Session 服务。
3. 校验返回结果，取得 OpenID；如启用开放平台，可保存 UnionID。
4. 以 OpenID 查找或创建 USER。
5. 颁发 Help Cat 自己的 Session，不把微信 session_key 发给客户端。
6. 对微信错误码、超时和频率限制做明确处理和监控。

官方登录服务文档：<https://developers.weixin.qq.com/miniprogram/dev/server/API/user-login/>。

### 4. 图片和隐私

- `wx.chooseMedia` 继续声明相册和相机，让用户自主选择来源。
- 上传前检查大小、格式和用户提示；服务端继续做真实签名校验。
- 进入对象存储阶段前清理 EXIF，避免照片携带精确 GPS。
- 明确说明精确位置用途、保存期限、展示范围和删除方式。
- 未获得必要授权时允许用户手填模糊位置，不把定位作为建档硬门槛。

官方媒体选择文档：<https://developers.weixin.qq.com/miniprogram/dev/api/media/video/wx.chooseMedia.html>。

隐私保护指引说明：<https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/>。

### 5. 产品和治理补齐

正式审核前至少完成：

- 隐私政策、用户协议和联系渠道。
- 账号注销与个人数据删除申请。
- 用户内容举报、审核、申诉和处置规则。
- 猫咪精确位置保护和高风险信息展示规则。
- 图片内容安全审核与人工复核路径。
- 网络失败、登录过期、拒绝定位、拒绝相册权限等状态。

### 6. 测试与发布

1. 开发版联调真实 AppID 与测试账号。
2. 体验版进行 iOS/Android、多型号、弱网和权限拒绝测试。
3. 验证微信登录、相册、相机、上传、定位、建档、小区、任务和退出。
4. 检查接口日志中没有 AppSecret、session_key、Token 或精确位置泄漏。
5. 提交审核前固定后端版本和回滚方案。
6. 审核通过后灰度发布，监控登录成功率、API 错误率、上传失败率和审核积压。

## 建议的代码改造

- `miniapp/app.js`：从构建环境读取正式 API Base，不在源代码中硬编码示例域名。
- `miniapp/utils/api.js`：统一错误码、Token 过期重登、超时和请求追踪 ID。
- `pages/cats/new`：使用小区 ID 选择器，不再只按名称取搜索结果第一项。
- 新增账号与隐私页：协议、注销、授权管理和数据说明。
- 新增版本配置：开发、体验、生产环境分离。
- 后端实现真实 `WechatProvider.exchange_code()` 并增加官方错误码测试。

## 上线门禁

以下条件全部满足前，不标记“小程序已上线”：

- HTTPS 证书和域名可用。
- 合法域名配置生效。
- 真实 code2Session 成功。
- AppSecret 只存在服务器安全配置中。
- 隐私指引、用户协议、注销和数据删除可用。
- 真机核心流程通过。
- 生产监控、备份和回滚可用。
- 微信审核通过并完成灰度验证。
