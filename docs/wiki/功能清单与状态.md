# 功能清单与状态

状态说明：

- **已实现**：代码、接口和自动化测试均存在，并已进入当前生产版本或待发布分支。
- **部分实现**：存在代码骨架或单一链路，但还不满足正式生产要求。
- **未实现**：只在路线图中，不能作为当前能力对外承诺。

## H5 用户端

| 功能 | 状态 | 入口与行为 | 已知限制 |
|---|---|---|---|
| 响应式首页 | 已实现 | 首页展示猫咪、开放任务和隐私说明 | 当前区域文案固定为富阳区/银湖街道 |
| 猫咪公开档案 | 已实现 | 搜索、按小区筛选、健康状态、图片和占位图 | 没有详情页、时间线和医疗记录 |
| 账号注册/登录/退出 | 已实现 | 用户名密码注册，Bearer Session 恢复 | 未实现找回密码、手机号、注销账号 |
| 超级管理员识别 | 已实现 | “我的”页显示超级管理员文案 | 已打开的旧页面需版本提示或手动刷新 |
| 管理后台快捷入口 | 已实现 | ADMIN/SUPER_ADMIN 在“我的”页进入后台 | Token 失效时后台要求重新登录 |
| 猫咪三步建档 | 已实现 | 基本信息、小区位置、照片说明 | 普通用户每日最多 3 条 |
| 手机相册/相机选择 | 已实现 | 系统图片选择器，可选择相册或拍摄 | 浏览器和系统可能显示不同选择界面 |
| 图片预览和校验 | 已实现 | JPEG/PNG/WebP，前端预览，后端签名检查 | 单图、最大 5 MiB；未压缩或裁剪 |
| 模糊位置和定位 | 已实现 | 可手填；安全上下文下可请求定位 | HTTP + IP 下定位能力可能受浏览器限制 |
| 小区建议 | 已实现 | 普通用户提交后等待管理员审核 | 未通过或归档小区不可用于新档案 |
| 管理员新增小区 | 已实现 | ADMIN/SUPER_ADMIN 新增后立即开放 | 当前城市、区县使用后端默认值 |
| 创建猫咪时新增小区入口 | 已实现 | 找不到小区时跳转到角色感知的小区表单 | 需要先创建小区，再返回选择 |
| 我的提交 | 已实现 | 查看本人猫咪和小区提交状态 | 暂无分页和历史筛选 |
| 救助任务浏览/领取 | 已实现 | 查看 OPEN 任务并领取 | 暂无完成、取消、转派和任务讨论 |
| 在线版本更新提示 | 已实现 | 发现服务器版本变化后提示刷新 | 不强制刷新，避免丢失表单 |

## 后端 API 与数据

| 功能 | 状态 | 说明 |
|---|---|---|
| FastAPI REST API | 已实现 | 认证、小区、猫咪、任务、媒体和管理接口 |

| SQLite 生产数据库 | 已实现 | 当前单机 MVP 使用 |
| Alembic 迁移骨架 | 已实现 | `001_initial.py` 和运行配置存在 |
| MySQL 驱动与容器样例 | 部分实现 | `.env.example` 指向 MySQL，生产仍是 SQLite |
| PostgreSQL | 未实现 | 大规模生产推荐目标数据库 |
| 对象存储/CDN | 未实现 | 图片当前保存在服务器本地目录 |
| Redis 会话/限流 | 未实现 | 当前没有分布式会话或集中限流 |
| 消息队列 | 未实现 | 没有异步图片处理、通知或审核任务 |
