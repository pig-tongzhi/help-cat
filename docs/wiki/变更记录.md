# 变更记录

## 2026-08-02：高级萌宠社区 UI 与小区候选联审

状态：待本次生产验收完成后更新为“已上线”。

- H5 视觉升级为暖白、深墨、杏色与雾紫/薄荷点缀的高级萌宠社区风格，保留真实猫咪照片优先。
- 管理后台同步高级视觉与手机/平板/桌面响应式布局。
- 双端底部加入“安得广厦千万间，大庇天下小猫俱欢颜”。
- 后台左上猫头改为 `/help-cat/rescue/index.html#home`，不在 URL 中传递 Token。
- 猫咪建档第二步支持“选择已有小区/填写新小区”双模式。
- 新候选小区与猫咪在同一事务创建；失败不留下孤立数据。
- 增加 `PENDING_REVIEW / NEEDS_CHANGES / ACTIVE / MERGED / REJECTED / ARCHIVED` 候选治理状态。
- 创建者可修正本人待审/待补充候选；管理员和超级管理员可核准、退回、合并或驳回无效内容。
- 合并会事务改挂所有关联猫咪并记录审计；猫咪在小区 ACTIVE 前不能公开。
- 增加 `version` 乐观锁，过期编辑/审核/合并返回 HTTP 409。
- `version` 覆盖候选编辑/审核/合并/归档和单只猫咪改挂；过期写入返回 HTTP 409。
- 候选被驳回、隐藏或归档后，管理员可搜索全部 ACTIVE 小区并将关联猫咪改挂后继续审核。
- 猫咪、小区、任务、本人提交和用户列表使用稳定游标分页，默认 24、最大 100。
- 后台联审使用服务端关联总数和最多 3 只预览，合并目标通过服务端搜索，不受当前 24 条页面限制。
- 猫咪 payload 直接携带小区名称/街道，跨页加载不会退化成“社区范围内”。
- H5 猫咪建档增加用户作用域 `Idempotency-Key`；丢包重试不重复创建、不重复扣配额。
- 新增数据库级有效小区规范名唯一约束、猫咪幂等唯一约束和合并目标自外键。
- 新增 `002_community_candidates`、`003_scale_integrity` 迁移及旧 SQLite 安全回填/碰撞归并。
- Alembic 显式读取 `HELPCAT_DATABASE_URL`，避免正式部署误迁移默认相对路径。
- 保留旧审核 payload 到历史 HIDDEN 状态的滚动发布兼容。
- 修复公开/管理员双视图对已撤销管理员 Session 的识别，退出后的旧 Token 不能读取待审猫咪。
- 生产副本迁移演练：001 → 002 → 003；六类数据行数与核心 ID 哈希不变，完整性 `ok`、外键违规 0、孤儿猫咪 0。
- 当前门禁：Python 64 项、Node 17 项，共 81 项；macOS 系统 Python 因未安装 Alembic 跳过 1 项真实迁移用例，该用例已在生产虚拟环境和生产数据库副本上通过。最终发布记录还会补充生产入口验收结果。
