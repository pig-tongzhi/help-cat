# 帮帮小猫 Help Cat

“帮帮小猫”是一个面向社区流浪猫档案、协作救助与治理审核的公益应用。项目当前提供响应式 H5、独立管理后台、FastAPI 后端和微信小程序代码骨架。

## 当前阶段

当前版本已经完成真实账号登录、角色权限、社区猫档案、小区治理、救助任务、图片上传和后台审核闭环，可用于小范围社区试运行。

当前生产架构仍是单机服务、SQLite 数据库和本地图片存储，**尚未达到几十万用户规模，也尚未完成微信小程序正式发布条件**。详细差距与升级顺序见 [[规模化路线图]] 和 [[微信小程序接入]]。

## 核心产品原则

1. 精确位置默认受保护。公开页面只展示人工填写的模糊位置。
2. 普通用户提交内容必须经过治理。管理员内容可以直接开放，但仍保留审计记录。
3. 唯一超级管理员不可被降级；超级管理员可以给普通用户授予或撤销管理员权限。
4. 前端按钮不是权限边界。所有管理操作都由后端再次校验角色。
5. 上线必须可回滚。静态资源和后端发布前先备份，上传后比较 SHA-256。
6. 文档必须区分“已经实现”和“路线图”，不能把规划描述成生产能力。
