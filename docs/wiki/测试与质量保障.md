# 测试与质量保障

## 自动化测试结构

### 后端 API

`server/tests/test_commercial_api.py` 使用临时数据库和真实 FastAPI 应用验证：

- 注册、登录、会话恢复与退出。
- USER、ADMIN、SUPER_ADMIN 权限边界。
- 唯一超级管理员不可修改。
- 普通用户小区待审、管理员小区直接开放。
- 猫咪每日配额、审核和可见性。
- 任务领取竞争状态。
- 图片类型、大小、签名和所有权。

### 前端合同

- `tests/test_rescue_h5_contract.py`：H5 页面结构、真实 API、角色入口、小区流程、响应式断点、图片选择、版本提示和静态资源顺序。
- `tests/test_commercial_frontends.py`：管理后台功能、权限入口和 API 路由合同。

### 前端行为

- `tests/js/admin_session_runtime.test.js`：真实执行后台退出，验证服务端注销请求、双 Token 清理、网络失败和防重复点击。
- `tests/js/rescue_version_runtime.test.js`：真实执行版本比较，验证同版本、新版本、非 2xx、无版本标记和网络失败。

### 数据与迁移

- `tests/test_commercial_migrations.py`：数据库迁移和结构。
- `tests/test_help_cat_qa_seed.py`：QA 数据可重复生成。
- `tests/test_help_cat_qa_cleanup.py`：QA 数据清理范围和预览安全。

测试数量会随功能增加，以命令的实际输出为准，不在文档中把历史数量当成永久指标。

## TDD 要求

每个新功能和缺陷修复遵循：

1. 写一个能够复现缺口的最小测试。
2. 运行并确认测试因预期原因失败。
3. 实现最小修改。
4. 运行聚焦测试变绿。
5. 运行完整回归，确认没有破坏其他流程。
6. 独立提交，便于审查和回滚。

## 生产 QA 数据

项目包含生产 QA 数据生成和清理脚本。QA 数据使用明确命名空间，覆盖：

- 普通用户、管理员。
- ACTIVE、PENDING_REVIEW、HIDDEN、ARCHIVED 小区。
- 已通过、待审核、未通过和隐藏猫咪。
- 开放与已领取任务。
- 图片正常、占位和异常加载场景。

生成前备份数据库；清理脚本默认预览，只允许清理 manifest 中记录的 QA 实体，不能按宽泛前缀删除真实数据。

## 上线验收矩阵

| 场景 | 预期 |
|---|---|
| USER 登录 | 显示志愿者文案，无后台入口 |
| ADMIN 登录 | 显示管理员文案，有后台入口 |
| SUPER_ADMIN 登录 | 显示超级管理员文案，有后台入口 |
| 后台快捷入口 | 无需再次输入密码进入后台；失效 Token 回登录页 |
| USER 新增小区 | PENDING_REVIEW，不出现在公开选择 |
| ADMIN/SUPER_ADMIN 新增小区 | ACTIVE，立即可选 |
| 小区审核通过 | 进入公开列表 |
| 手机选择照片 | 可选择相册或拍摄，不强制后置相机 |
| 旧页面遇到新版本 | 显示更新提示，不清空表单 |
| 普通猫咪提交 | 待审核且每日配额生效 |
| 管理员猫咪提交 | 直接 APPROVED |
| 生产健康和哈希 | API 正常，静态文件与 release 一致 |

## 设备与浏览器

最低回归覆盖：

- 360 px 小屏手机。
- 390/430 px 主流手机。
- 768/820 px 平板。
- 1024 px 横屏平板/小桌面。
- 1280 px 及以上桌面。

重点检查横向溢出、底部导航、安全区、弹层滚动、键盘遮挡、图片选择、长文本和无图片状态。

## 已知质量缺口

- 当前前端测试以合同测试为主，缺少完整的端到端浏览器测试套件。
- 应用内浏览器自动化曾受外部遥测网络超时影响，不能用工具超时替代产品结果判断。
- 没有持续集成工作流自动运行测试。
- 没有性能、容量、故障注入、无障碍扫描和安全扫描流水线。
- 没有生产 SLO 和错误预算。

进入大规模推广前应把这些项目转为自动门禁，而不是依赖人工记忆。
