# 帮帮小猫品牌与 77 首屏精修设计

## 目标与唯一参考

以用户确认的示范图 `codex-clipboard-85611778-55d9-47b3-ae5d-dd00b018b740.png` 为唯一视觉基准。此次不改变首页信息架构，只修复品牌标志不一致和首屏左右背板割裂，并提升细节完成度。

## 品牌标志

- 从示范图的猫头造型重新绘制一个代码原生 SVG 母版：白色猫脸、细墨色轮廓、右眼大面积黑斑、小粉鼻、克制的眼睛与嘴部线条。
- 标志必须在 16px favicon、32–44px 页头和 64px 登录页三种尺度都清楚，轮廓不得因缩放糊成黑块。
- `helpcat-77-mark.svg` 是唯一母版；favicon 直接复用同一几何，不再维护第二套手绘形状。
- Apple Touch Icon、PWA 192/512 图标由该母版生成，页头、登录页、管理后台全部引用同一品牌资产。
- 所有引用增加新版本指纹，避免浏览器沿用旧 favicon 或旧页头图标。

## 77 首屏

- 整个 hero 使用连续的暖白背景 `#F5F1EB`，不允许左右两块纯色拼接，也不允许在 50% 位置出现边线或色阶跳变。
- 77 图片保留真实面部、双耳、双眼和右眼黑斑；图片背景融合到相同暖白色，主体边缘自然，不做卡通化。
- 桌面：左侧文案约 42%，77 占右侧约 58%，脸部视觉中心靠右下，整体仍保持示范图的大留白与编辑感。
- 手机：使用独立竖向裁切，77 位于右侧，文案位于左侧；不裁掉耳朵、眼睛或黑眼斑。
- hero、指标条、内容卡之间仅用细灰线建立层级，不使用厚重阴影、渐变紫色或大圆角装饰。

## 页面精致度规则

- 容器最大宽度、页头高度、标题基线、四项指标分隔线和卡片间距按示范图比例收紧。
- 档案卡保持真实图片优先，统一图片比例、边框、标题与地区基线。
- 桌面不出现底部导航；手机底部导航固定但不遮挡正文。
- 空状态与真实数据共享同一栅格，不因数据为空导致页面坍塌或出现大面积突兀虚线框。

## 验收门禁

- 契约测试验证所有品牌入口引用同一母版和同一版本号。
- 自动检查桌面 hero 左右背景色一致、无中间分割边框；手机和桌面均无横向溢出。
- 在 1440×900、390×844 两个视口生成实拍，与示范图并排检查 logo 轮廓、hero 背景连续性、77 裁切、指标与卡片布局。
- 推送及部署前运行后端、前端、Node 和 JavaScript 语法全量门禁；正式域名受备案阻断期间，额外通过公网 IP 页面验收发布文件。
