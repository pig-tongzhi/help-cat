# 77 故事媒体可靠性设计

## 目标

保留用户确认的白底黑眼斑 Logo 母版，并让 77 故事中的每张照片在桌面和手机完整可见、出现网络失败时可恢复。

## 方案

不再重绘 Logo；H5、后台、favicon 与小程序继续引用同一母版及其既有派生图。故事照片保留当前经过隐私处理的静态 WebP 文件，但容器改用 `object-fit: contain` 和统一暖白背景，禁止裁切。图片加载失败时显示可点击的重试控件，该控件通过带时间戳的同一 URL 重载图片。

## 验证

测试确保故事图的完整展示契约与重试标记存在、Logo 单一母版引用未被破坏；发布后逐一请求三张图片并在桌面/手机视口截图检查。
