# 图片加载优化设计

## 目标

让猫咪列表在移动网络下优先加载小尺寸 WebP 缩略图，保留原图作为故障兜底，并避免重复下载不可变图片。

## 方案

每个媒体文件在存储目录中拥有一个同名的 `*.thumb.webp` 派生文件。上传成功时立即生成；历史图片第一次请求缩略图时按需生成。接口通过 `?variant=thumb` 返回最长边不超过 640 像素的 WebP，原图和缩略图均返回一年的不可变缓存头。

H5 与微信小程序列表默认请求缩略图。H5 缩略图加载失败时只重试一次原图；原图也失败才显示现有的“暂无照片”占位，保证不会出现半张破图。

## 边界与验证

不迁移数据库、不改媒体 ID，也不破坏既有原图 URL。测试覆盖新上传缩略图、历史图片按需生成、缓存头，以及前端缩略图/一次兜底契约。
