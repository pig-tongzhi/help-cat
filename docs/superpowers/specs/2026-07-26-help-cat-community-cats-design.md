# 帮帮小猫社区猫咪档案与任务权限设计

## 目标

将现有银湖街道救助 H5 试验页升级为“帮帮小猫 / Help Cat”第一阶段产品：普通用户可以按街道或小区搜索猫咪档案、查看自己提交的待审核档案、每天创建不超过 3 条猫咪档案，并查看/领取管理员发布的任务；上报和任务管理权限仍只归管理员。

## 已确认范围

- 首期区域：杭州市富阳区银湖街道。
- 层级：城市 → 区 → 街道 → 小区 → 投喂点 → 猫咪档案。
- 普通用户可查看已审核档案，也可创建猫咪档案。
- 普通用户创建的档案进入 `PENDING_REVIEW`，创建者可以在“我的提交”中看到完整内容和审核状态。
- 每个普通用户按自然日最多创建 3 条猫咪档案；管理员不受此限制。
- 普通用户可以看到管理员发布的开放任务并领取任务。
- 任务创建、编辑、关闭、上报创建与管理、审核、数据导出均为管理员权限。
- 暂时不实现正式注册登录；浏览器 H5 使用稳定的本地演示用户身份模拟配额和“我的提交”，正式登录在下一期接入时替换身份提供器。
- 地图先使用高德地图选择器的适配边界；没有 API Key 时使用小区名称/手工位置回退，不阻塞档案创建。
- 公开页面可展示猫咪图片、名称、状态和投喂点定位信息；精确坐标默认用于地图导航，但不展示猫窝/家庭等敏感位置。

## 方案选择

1. **匿名浏览器身份（本期采用）**：保留现有无后端 H5 体验，用 `help-cat-user-id` 生成本地用户 ID，服务层也接受 `actor_id`。优点是无需等待登录配置，能验证完整业务闭环；缺点是清除浏览器数据后配额会重置，不能作为生产级反刷方案。
2. **手机号/微信轻量登录**：能可靠限制每日 3 条并跨设备查看“我的提交”，但需要短信或微信配置，超出当前无密钥 MVP 范围。
3. **管理员直录**：最简单，但无法验证普通用户建档和任务领取，不符合本期目标。

## 信息架构与交互

- 顶部品牌固定显示“帮帮小猫 Help Cat”，区域标签显示“富阳区 · 银湖街道”。
- 总览页提供街道/小区搜索框。输入小区名称时只显示匹配小区的投喂点和猫咪；无匹配时显示空状态，不展示其他小区档案。
- 猫咪卡片展示：档案编号、名称、照片占位/图片 URL、性别、毛色、健康状态、TNR 状态、居住/活动情况、所属小区/投喂点、地图定位入口。
- “我的提交”只展示当前演示身份创建的档案，包括待审核、已通过、已驳回状态；其他用户的待审核档案不公开。
- 首页任务提示框只显示开放任务数量和最近任务摘要；点击任务页可查看详情并领取。领取后任务归属当前身份，不能被第二个用户重复领取。
- 管理页保留管理员演示入口，并明确显示普通用户不能创建上报、管理任务或导出数据。

## 权限矩阵

| 能力 | 普通用户 | 管理员 |
|---|---:|---:|
| 搜索街道/小区 | 允许 | 允许 |
| 查看已审核猫咪档案 | 允许 | 允许 |
| 查看自己的待审核档案 | 允许 | 允许 |
| 创建猫咪档案 | 每日最多 3 条 | 允许 |
| 修改/删除猫咪档案 | 不允许 | 允许 |
| 创建/编辑/审核上报 | 不允许 | 允许 |
| 创建/编辑/关闭任务 | 不允许 | 允许 |
| 查看开放任务 | 允许 | 允许 |
| 领取开放任务 | 允许 | 允许 |
| 管理投喂点/地图信息 | 不允许 | 允许 |
| 物资、日志、导出 | 不允许 | 允许 |

## 数据与状态

在现有内存模型基础上新增：

- `CatProfile.created_by`：创建者身份。
- `CatProfile.review_status`：`PENDING_REVIEW`、`APPROVED`、`REJECTED`。
- `CatProfile.photo_url`、`living_status`、`location_note`：档案展示字段。
- `RescueTask.description`、`created_by`、`published`：管理员发布任务所需字段。
- `RescueTask.assignee_id` 可由普通用户或管理员领取。
- 服务维护按 `actor_id + Asia/Shanghai calendar date` 统计建档次数；重复调用不绕过配额。

展示规则：已审核档案对所有用户可见；待审核档案仅创建者和管理员可见；驳回档案仅创建者和管理员可见。

## 错误与边界

- 未填写小区、猫咪名称或活动情况：拒绝创建。
- 每日已创建 3 条：返回 `daily_cat_limit_reached`，不产生档案。
- 非创建者访问待审核档案：返回 `forbidden`，不泄露内容。
- 普通用户试图创建上报、创建任务、审核、导出：返回 `forbidden`。
- 任务已被领取：第二个领取者收到 `task_already_claimed`，状态和日志不变。
- 搜索无结果：返回空列表和明确空状态，不回退展示全部区域。
- 地图 API 不可用：保留小区/投喂点文字定位，不阻塞保存。

## 测试与验收

必须覆盖：品牌文案、街道/小区过滤、无结果、普通用户建档、每日第 4 条失败、管理员不受限、创建者查看待审核、他人隔离、审核后公开、管理员上报/任务权限、普通用户查看/领取任务、并发领取仅一人成功、地图回退、敏感字段不公开、日志和回归测试。

## 非本期

- 正式手机号/微信注册登录与密码/Token。
- 实名认证、志愿者认证、权限审批流。
- 复杂社区运营、支付、捐赠、消息推送。
- TNR、物资、受伤上报的普通用户开放权限。
