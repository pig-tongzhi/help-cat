# Help Cat 手机照片选择与管理后台入口设计

## 目标

修复手机端猫咪建档时只能直接调用相机、无法选择手机相册的问题；同时让 `ADMIN` 和 `SUPER_ADMIN` 登录用户端后能够直接进入管理后台，并复用当前登录状态。

## 范围

本次只修改救助 H5 的上传控件、账号卡片、角色展示、管理后台跳转以及对应自动化测试和静态资源版本。后端权限模型、管理后台功能、图片格式限制和上传接口保持不变。

## 手机照片选择

猫咪照片控件保留 `type="file"` 和 `accept="image/*"`，移除 `capture="environment"`。手机浏览器据此使用系统原生选择器，让用户自行选择相册、拍照或文件；桌面浏览器继续显示文件选择器。

现有 JPEG、PNG、WebP 校验、预览、移除照片和上传失败保留表单的行为保持不变。用户取消系统选择器时不清空已有表单内容，也不发起上传。

## 管理后台入口

“我的”账号卡片增加隐藏的“进入管理后台”按钮。只有当前用户角色为 `ADMIN` 或 `SUPER_ADMIN` 时显示；未登录用户和 `USER` 始终隐藏。

点击按钮时，将用户端当前 Bearer Token 写入管理后台现有的 `help_cat_admin_token` 会话键，然后导航到 `/help-cat/admin/`。因为两个页面部署在同一来源下，管理后台可以通过已有的会话恢复逻辑验证令牌并直接打开；如果令牌已失效，管理后台仍回退到登录界面，不绕过后端鉴权。

账号名称和说明同时识别 `SUPER_ADMIN`：超级管理员显示“超级管理员账号”，普通管理员显示“管理员账号”，两者的新建档案均由后端按现有权限直接公开。

## 权限与安全

前端按钮显隐仅用于体验，不作为安全边界。管理后台继续调用 `/api/v1/auth/me` 验证角色；`ADMIN` 只能使用内容治理能力，`SUPER_ADMIN` 才能加载用户列表和修改普通用户角色。系统不增加创建第二个超级管理员的入口。

Token 只在同源 `sessionStorage` 中复制，不写入 URL、日志或长期存储。退出用户端时继续撤销当前服务端会话；失效令牌无法进入后台。

## 错误处理

- 用户取消选择照片：保持当前表单和预览状态，不提示错误。
- 选择不支持的文件：沿用现有格式错误提示并清空无效文件。
- 后台令牌失效：后台显示原有登录页。
- 普通用户直接访问后台地址：后台完成身份检查后拒绝并返回登录页。

## 测试与验收

自动化契约测试必须先证明当前实现失败，再覆盖：

1. 上传控件保留 `accept="image/*"` 且不存在 `capture` 属性。
2. 页面存在默认隐藏的管理后台入口。
3. 入口仅对 `ADMIN` 和 `SUPER_ADMIN` 显示。
4. 超级管理员角色文案正确。
5. 点击入口会同步管理后台令牌并导航到 `/help-cat/admin/`。
6. 普通用户看不到入口，后台现有权限测试继续通过。

浏览器验收覆盖桌面、平板和手机宽度；生产环境验证用户端可访问、API 健康、管理员跳转成功、普通用户隔离正常。部署前备份当前静态资源，部署后更新静态资源版本号并验证没有控制台错误。
