# 帮帮小猫大厂公益风改版设计

## 目标

将当前“演示身份 + localStorage + 单页长表单”的帮帮小猫 H5，升级为可公开使用的移动端公益产品体验；同时修复管理员建档仍需审核、普通用户可见管理入口、定位不可用、账号验证缺失和线上/本地资源不一致等问题。改版完成后部署到 `http://175.178.41.19/help-cat/rescue/index.html`。

## 已确认方案

采用微信/支付宝式成熟公益产品风：暖白背景、品牌橙、深墨绿正文、低饱和状态色、统一线性图标和清晰的信息层级。移除 Emoji 主视觉、演示身份切换、重置演示和体验版文案。

## 信息架构

用户端使用四个一级入口：

1. 首页：区域概况、附近猫咪、待领取任务、快捷建档。
2. 猫咪档案：按小区/名称搜索、状态筛选、档案详情。
3. 救助任务：开放任务、领取状态和我的任务。
4. 我的：登录状态、我的提交、审核结果和退出登录。

管理能力不出现在普通用户端，继续使用独立的 `/help-cat/admin/` 管理端。

## 页面与组件

- 顶部品牌区：CSS 猫耳标识、帮帮小猫名称、银湖街道区域说明。
- 首页数据卡：已建档、待救助、已完成三个核心指标。
- 猫咪卡片：照片、昵称、编号、健康/TNR 状态、所属小区、模糊位置。
- 任务卡片：任务类型、地点、紧急度、状态和领取按钮。
- 建档流程：三步抽屉/页面——基本信息；小区与位置；照片与说明。
- 登录页：账号密码登录/注册；登录成功保存会话令牌，失效后统一退出并提示。
- 状态组件：骨架屏、空状态、错误提示、成功反馈、权限提示。

## 数据流与权限

用户端以 `/help-cat-api/api/v1` 为唯一业务数据源，不再把 localStorage 作为猫咪、任务或审核数据源。浏览器只在 `sessionStorage` 保存访问令牌和必要的界面状态。

- 未登录用户：可查看公开小区、已审核猫咪和开放任务；提交、领取时进入登录。
- 普通用户：可提交小区和猫咪、查看自己的审核状态、领取任务；每日最多提交三只猫。
- 管理员：建档时 `review_status` 直接为 `APPROVED`；普通用户建档为 `PENDING_REVIEW`。
- 管理员入口不在用户端展示；服务端仍对每个管理接口执行角色校验。
- 会话过期、撤销或用户停用时返回统一错误码，前端清理令牌并回到登录页。

## 小区与位置

建档必须关联有效小区，但用户不必从冗长下拉框查找：使用可搜索组合框，支持按名称搜索现有小区；未找到时可提交新小区建议，审核通过后再建档。

浏览器地理定位只在安全上下文可用。当前 HTTP IP 环境中不承诺自动定位：

- 若 `navigator.geolocation` 可用，允许用户授权后填入坐标。
- 若不可用、拒绝或超时，立即切换为“小区 + 位置描述”手工模式。
- 公开接口和界面不展示精确坐标，仅展示脱敏位置说明。

## 错误处理

- 网络错误：保留当前页面数据，展示可重试提示。
- 401：清理令牌并要求重新登录。
- 403：显示无权限，不渲染管理操作。
- 409：显示重复小区或任务已领取等业务冲突。
- 429：显示当天建档额度已用完。
- 图片错误：限制 JPEG/PNG/WebP 和大小，上传失败不丢失已填写表单。
- 表单错误：字段旁就地提示，提交按钮不重复触发。

## 兼容与性能

- 原生 HTML/CSS/JavaScript，不引入重型 UI 依赖。
- 以 390×844 为主验收尺寸，同时覆盖 320、375、430 和桌面宽度。
- 首屏不依赖大图；CSS 和脚本使用版本化资源 URL 防止旧缓存。
- 触控目标不小于 44px，正文不小于 14px，状态不只依赖颜色表达。

## 测试与上线门禁

自动化测试必须覆盖：登录/注册/退出/会话失效、公开数据加载、管理员建档免审、普通用户待审核与每日配额、社区搜索、我的提交、任务并发领取、图片校验、权限隔离、错误码映射和静态资源契约。

浏览器验收必须覆盖：移动端无横向溢出、底部导航、搜索空状态、登录失败/成功、三步建档、定位降级、任务领取、管理员入口隔离、刷新后会话行为、控制台无错误。

上线前执行完整 Python 测试、JavaScript 语法检查、静态契约测试、API 冒烟和 Nginx 配置检查。部署先备份线上资源，覆盖后校验哈希、HTTP 200、API 健康检查和关键页面文案；失败则恢复备份。

## 非本次范围

- 在没有域名、TLS、微信 AppID/AppSecret 的前提下实现真实微信登录。
- 第三方地图 SDK、支付、捐赠和消息推送。
- 将 SQLite 迁移到 MySQL；本次保持现有数据库，避免在 UI 改版中混入高风险迁移。
